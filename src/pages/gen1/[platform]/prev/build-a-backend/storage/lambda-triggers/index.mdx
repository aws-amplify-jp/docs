Storage カテゴリーで Amazon S3 と Amazon DynamoDB をプロバイダーとしてトリガーを有効にする場合、CLI は S3 および DynamoDB イベントへの Lambda トリガーの関連付けをサポートしています。例えば、これは Amplify CLI で管理される DynamoDB テーブルの作成または更新操作後に Lambda 関数を呼び出す場合に便利です。

このトピックの詳細については、Amplify CLI ドキュメントの [ファイルストレージ Lambda トリガー](/gen1/[platform]/tools/cli/usage/lambda-triggers/#s3-lambda-triggers) をご覧ください。
