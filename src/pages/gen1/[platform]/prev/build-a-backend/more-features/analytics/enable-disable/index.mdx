## アナリティクスの無効化

アナリティクスはアプリで設定すると、デフォルトで有効になります。アプリのアナリティクスを無効化するには、`disable`関数を使用してください：

import android0 from '/src/fragments/lib-v1/analytics/android/enable-disable/disable.mdx';

<Fragments fragments={{ android: android0 }} />

import ios0 from '/src/fragments/lib-v1/analytics/ios/enable-disable/disable.mdx';

<Fragments fragments={{ swift: ios0 }} />

import flutter0 from '/src/fragments/lib-v1/analytics/flutter/enable-disable/disable.mdx';

<Fragments fragments={{ flutter: flutter0 }} />

import js0 from '/src/fragments/lib-v1/analytics/js/enable-disable/disable.mdx';

<Fragments
  fragments={{
    javascript: js0,
    angular: js0,
    nextjs: js0,
    react: js0,
    vue: js0
  }}
/>

import reactnative0 from '/src/fragments/lib-v1/analytics/js/enable-disable/disable.mdx';

<Fragments fragments={{ 'react-native': reactnative0 }} />

アナリティクスを有効化するには、アプリで`enable`関数を使用できます：
