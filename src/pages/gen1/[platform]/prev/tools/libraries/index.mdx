Amplify のオープンソース クライアント ライブラリは、クラウドを活用したさまざまなカテゴリの操作にわたって、ユースケース中心で使いやすいインターフェースを提供し、モバイルおよび Web 開発者がバックエンドと簡単にやり取りできるようにします。これらのライブラリは AWS Cloud によって支えられています。ライブラリは、Amplify CLI を使用して作成された新しいバックエンドと既存のバックエンド リソースの両方で使用できます。
