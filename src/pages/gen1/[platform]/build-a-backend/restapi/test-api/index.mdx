## ターミナルからAPIをテストする

ゲストユーザーがREST APIにアクセスできる場合は、Curlを使用してターミナルからテストできます。

[Curl](https://github.com/curl/curl)は、様々なプロトコルを使用してサーバーとの間でデータを転送できるコマンドラインツールです。

> CurlはMac、Windows、Linuxを含む多くのディストリビューションで利用可能です。[ドキュメント](https://curl.haxx.se/docs/install.html)のインストール手順に従ってください。

<BlockSwitcher>
<Block name="Mac and Linux">

### GETメソッドの例

```bash
curl https://a5b4c3d2e1.execute-api.eu-west-2.amazonaws.com/dev/todos
```

### POSTメソッドの例

```bash
curl -H "Content-Type: application/json" -d '{"name":"todo-1"}' https://a5b4c3d2e1.execute-api.eu-west-2.amazonaws.com/dev/todos
```

</Block>
<Block name="Windows">

### GETメソッドの例

```bash
curl https://a5b4c3d2e1.execute-api.eu-west-2.amazonaws.com/dev/todos
```

### POSTメソッドの例

```bash
curl -H "Content-Type: application/json" -d {\"name\":\"todo-1\"} https://a5b4c3d2e1.execute-api.eu-west-2.amazonaws.com/dev/todos
```

</Block>

> 重要! 本番環境のエンドポイントを使用したテストメソッドは、元に戻せないリソースの変更につながる可能性があります。

## Amplify MockでAPIをテストする

Amplify CLIを使用すると、`amplify mock function`コマンドを使用してREST APIを迅速にテストできます。

HTTPメソッド`GET`とパス`/todos?limit=10`(クエリ文字列パラメータ`limit`を含む)を使用して、以下のルートで新しいREST APIをテストしましょう。

```console
GET /todos?limit=10
```

> 重要! 本番環境のエンドポイントを使用したテストメソッドは、元に戻せないリソースの変更につながる可能性があります。

続行する前に、`{project}/amplify/backend/function/todosLambda/src/event.json`ファイルを編集して、テスト目的でその内容を置き換えます。

```json
{
  "httpMethod": "GET",
  "path": "/todos",
  "queryStringParameters": {
    "limit": "10"
  }
}
```

変更を保存したことを確認して、以下を実行します

```bash
amplify mock function todosLambda
```

次のオプションを選択します:

- `{project}/amplify/backend/function/todosLambda`に相対するイベントJSONオブジェクトのパスを指定してください __src/event.json__

## API Gatewayコンソールを使用してAPIをテストする

HTTPメソッド`GET`とパス`/todos?limit=10`(クエリ文字列パラメータ`limit`を含む)を使用して、以下のルートで新しいREST APIをテストしましょう。

```console
GET /todos?limit=10
```

> 重要! API Gatewayコンソールでテストメソッドを使用すると、元に戻せないリソースの変更につながる可能性があります。

- [https://console.aws.amazon.com/apigateway](https://console.aws.amazon.com/apigateway)でAPI Gatewayコンソールにサインインします。
- `todosApi` REST APIを選択します。
- リソースペインで、テストするメソッドを選択します。`/todos`の直下の`ANY`を選びます。

```console
/                        
 |_ /todos               Main resource. Eg: /todos
   ANY                   Includes methods: DELETE, GET, HEAD, OPTIONS, PATCH, POST, PUT
   OPTIONS               Allow pre-flight requests in CORS by browser
    |_ /{proxy+}         Proxy resource. Eg: /todos/, /todos/id, todos/object/{id}
    ANY                  Includes methods: DELETE, GET, HEAD, OPTIONS, PATCH, POST, PUT
    OPTIONS              Allow pre-flight requests in CORS by browser
```

- メソッド実行ペインのクライアントボックスで、TESTを選択します。`GET`メソッドを選択します。クエリ文字列`{todos}`フィールドに`limit=10`を追加します。

- テストを選択して`GET /todos?limit=10`のテストを実行します。リクエスト、ステータス、レイテンシ、レスポンスボディ、レスポンスヘッダ、ログが表示されます。
