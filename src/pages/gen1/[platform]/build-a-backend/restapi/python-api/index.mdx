このガイドでは、Python API をデプロイする方法を学習します。

## 1. 新しい Amplify プロジェクトを初期化する

```sh
amplify init

# Follow the steps to give the project a name, environment name, and set the default text editor.
# Accept defaults for everything else and choose your AWS Profile.
```

## 2. API と関数を追加する

```sh
amplify add api
```

CLI は、**amplify/backend/function/greetingfunction** に新しい関数を作成していることを確認できます。

## 3. 関数コードを更新する

次に、**amplify/backend/function/greetingfunction/src/index.py** を開き、コードを以下のように更新します。

```python
import json
import datetime

def handler(event, context):

  current_time = datetime.datetime.now().time()

  body = {
      'message': 'Hello, the current time is ' + str(current_time)
  }

  response = {
      'statusCode': 200,
      'body': json.dumps(body),
      'headers': {
        'Content-Type': 'application/json',
        'Access-Control-Allow-Origin': '*'
      },
  }

  return response
```

## 4. API をデプロイする

API をデプロイするには、`push` コマンドを実行します。

```sh
amplify push
```

## 5. API を使用する

API に GET リクエストを送信する方法は次のとおりです。

import js0 from '/src/fragments/guides/api-rest/js/python-api-call.mdx';

<Fragments

    vue: js0
  }}
/>

<Fragments fragments={{ swift: ios1 }} />

import android2 from '/src/fragments/guides/api-rest/android/rest-api-call.mdx';

<Fragments fragments={{ android: android2 }} />

Amplify を使用して REST API と相互作用する方法の詳細については、完全なドキュメント [こちら](/gen1/[platform]/build-a-backend/restapi/set-up-rest-api/) をご確認ください。

API エンドポイントは `aws-exports.js` フォルダにあります。

この URL と指定されたパスを使用して、API と直接相互作用することもできます。

```sh
curl https://<api-id>.execute-api.<api-region>.amazonaws.com/<your-env-name>/hello
```
