## 既知の問題

バンドラーを起動する際に、以下のエラーが発生する場合があります:

> Error: Unable to resolve module stream from /path/to/node_modules/@aws-sdk/...

これは[既知の問題](https://github.com/aws/aws-sdk-js-v3/issues/4877)です。このエラーを解決するには、[リンク先の issue](https://github.com/aws/aws-sdk-js-v3/issues/4877#issuecomment-1656007484) で説明されている手順に従ってください。
