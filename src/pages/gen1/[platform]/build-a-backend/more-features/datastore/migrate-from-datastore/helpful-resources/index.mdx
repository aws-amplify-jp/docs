## ローカルストレージパッケージ

DataStoreからの移行時に、いくつかのサードパーティパッケージを見つけました。これらのパッケージはメンテナンスされておらず、テストしたバージョンに限定した経験があります。

| 機能 | [isar-community](https://pub.dev/packages/isar_community) | [Drift](https://pub.dev/packages/drift) | [sqlite3](https://pub.dev/packages/sqlite3) |
|---|---|---|---|
| モデルスキーマ | ✅ | ✅ | ✅ |
| ネストされたモデル | ✅ | ✅ | ✅ |
| カスタム主キー | ✅ | ✅ | ✅ |
| CRUD | ✅ | ✅ | ✅ |
| クエリ述語 | ✅ | [where()を使用する必要あり](https://drift.simonbinder.eu/docs/dart-api/select/#where) | ✅ |
| Observe/ObserveQuery | ✅ | ✅ | [`updates`ストリーム経由](https://pub.dev/documentation/sqlite3/latest/common/CommonDatabase/updates.html) |

<Callout>

IsarはGradle 8をサポートしていません。これはAmplify Flutter Androidの要件ですが、これを解決する[フォーク](https://github.com/isar/isar/issues/1470#issuecomment-1978766200)があります。DriftはAmplify Flutterパッケージで使用されているため、使用できるDriftバージョンに制限が生じる可能性があります。

</Callout>
