[GraphQL Transform ライブラリ](/gen1/[platform]/build-a-backend/graphqlapi/custom-business-logic/#lambda-function-resolver)では、GraphQL API 内で AWS Lambda 関数リゾルバーを設定できる `@function` ディレクティブを提供しています。このガイドでは、`@function` ディレクティブを使用して、Lambda 関数を GraphQL リゾルバーとして使用し、他のサービスと API と相互作用する方法を学びます。

## 基本的なクエリとミューテーション関数リゾルバーの作成

まず、データソースが Lambda 関数に設定されているクエリとミューテーションを持つ GraphQL スキーマを見てみましょう。

```graphql
# 引数を返すクエリ
type Query {
  echo(msg: String): String @function(name: "functionName-${env}")
}

# 2 つの数値を加算するミューテーション
type Mutation {
  add(number1: Int, number2: Int): Int @function(name: "functionName-${env}")
}
```

`@function` ディレクティブを使用することで、GraphQL リゾルバーとして呼び出される Lambda 関数を指定できます。

このガイドでは、GraphQL API で Lambda 関数リゾルバーを有効にする方法を学びます。

### 関数の作成

まず、最初の Lambda 関数を作成します：

```sh
amplify add function

? Provide a friendly name for your resource to be used as a label for this category in the project: echofunction
? Provide the AWS Lambda function name: echofunction
? Choose the function runtime that you want to use: NodeJS
? Choose the function template that you want to use: Hello World
? Do you want to access other resources created in this project from your Lambda function? No
? Do you want to invoke this function on a recurring schedule? No
? Do you want to edit the local lambda function now? Yes
```

関数のコード（**amplify/backend/function/echofunction/src/index.js** にあります）を開いて、Enter キーを押します：

```js
exports.handler = async (event) => {
  const response = event.arguments.msg;
  return response;
};
```

この関数は、引数として渡された `msg` プロパティの値を返すだけです。

#### Lambda イベント情報

`event` オブジェクトには、以下のプロパティが含まれます：

```js
/*
event = {
  "typeName": "Query" or "Mutation", @function の使用場所に基づいて動的に入力されます
  "fieldName": @function の使用場所に基づいて動的に入力されます
  "arguments": { msg }, GraphQL フィールドの引数
  "identity": {}, AppSync アイデンティティオブジェクト
  "source": {}, 親リゾルバーによって返されたオブジェクト。例: 'Post.comments' フィールドを解決する場合、ソースは Post オブジェクトです
  "request": {}, AppSync リクエストオブジェクト。ヘッダーなどが含まれます
  "prev": {} 組み込みパイプラインリゾルバーサポートを使用している場合、これには前の関数によって返されたオブジェクトが含まれます。
}
*/
```

上記の関数では、`arguments` プロパティを使用して、関数に引数として渡された値を取得しています。

次に、別の Lambda 関数を作成します：

```sh
amplify add function

? Provide a friendly name for your resource to be used as a label for this category in the project: addingfunction
? Provide the AWS Lambda function name: addfunction
? Choose the function runtime that you want to use: NodeJS
? Choose the function template that you want to use: Hello World
? Do you want to access other resources created in this project from your Lambda function? No
? Do you want to invoke this function on a recurring schedule? No
? Do you want to edit the local lambda function now? Yes
```

次に、関数のコード（**amplify/backend/function/addingfunction/src/index.js** にあります）を以下に更新して、Enter キーを押します：

```js
exports.handler = async (event) => {
  /* number1 と number2 を加算し、結果を返す */
  const response = event.arguments.number1 + event.arguments.number2;
  return response;
};
```

この関数は 2 つの数値を一緒に加算し、結果を返します。

```graphql
type Query {
  echo(msg: String): String @function(name: "echofunction-${env}")
}

type Mutation {

```

これで関数と GraphQL API をデプロイできます：

```sh
amplify push
```

### GraphQL API のクエリ

これで、以下のクエリとミューテーションを実行して、API と相互作用できます：

```graphql
query echo {
  echo(msg: "Hello world!")
}

mutation add {
  add(number1: 1100, number2: 100)
}
```

## 別の API と相互作用するリゾルバーの作成

次に、公開の暗号通貨 REST API と相互作用する関数を作成します。

別の関数を作成します：

```sh
amplify add function
```

次に、関数のコード（**amplify/backend/function/cryptofunction/src/index.js** にあります）を以下に更新して、Enter キーを押します：

```javascript
const axios = require('axios');

exports.handler = async (event) => {
  let limit = 10;
  if (event.arguments.limit) {
    limit = event.arguments.limit;
  }
  const url = `https://api.coinlore.net/api/tickers/?limit=${limit}`;
  let response = await axios.get(url);
  return JSON.stringify(response.data.data);
};
```

次に、関数の **src** フォルダに axios ライブラリをインストールし、ルートディレクトリに戻ります：

```sh
cd amplify/backend/function/cryptofunction/src
npm install axios
cd ../../../../../
```

これで GraphQL スキーマを更新し、Query タイプに `getCoins` リゾルバーを追加します：

```graphql
type Query {
  echo(msg: String): String @function(name: "gqlfunc-${env}")
  getCoins(limit: Int): String @function(name: "cryptofunction-${env}")
}
```

次に、更新をデプロイします：

```sh
amplify push
```

これで、新しい `getCoins` クエリを使用して GraphQL API をクエリできます。

#### 基本的なクエリ

```graphql
query getCoins {
  getCoins
}
```

#### リミット付きクエリ

```graphql
query getCoins {
  getCoins(limit: 100)
}
```

`@function` ディレクティブの詳細については、GraphQL Transform ドキュメント[こちら](/gen1/[platform]/build-a-backend/graphqlapi/custom-business-logic/#lambda-function-resolver)を確認してください。
