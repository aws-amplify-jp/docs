AWS Amplifyストレージモジュールは、アプリケーション内のユーザーコンテンツをパブリック、保護、またはプライベートストレージバケット内で管理するためのシンプルなメカニズムを提供します。ストレージカテゴリには、[Amazon S3(Simple Storage Service)](https://docs.aws.amazon.com/AmazonS3/latest/dev/Welcome.html)の組み込みサポートが付属しています。

## S3の主要な概念

Amazon S3はデータをコンテナバケット内のオブジェクトとして保存します。オブジェクトはファイルと、そのファイルを説明するオプションのメタデータで構成されています。Amazon S3にオブジェクトを保存するには、保存したいファイルをバケットにアップロードします。ファイルをアップロードするときに、オブジェクトとそのメタデータのアクセス許可を設定できます。

バケットはオブジェクトのコンテナです。1つ以上のバケットを持つことができます。各バケットについて、それへのアクセスを制御(バケット内でオブジェクトを作成、削除、リストしたユーザー)でき、アクセスログを表示でき、Amazon S3がバケットとそのコンテンツを保存する地理的リージョンを選択できます。

## AWSサービスへのアクセス

ストレージの場合、ストレージアセットへのユーザーレベルのアクセスを理解することが重要です。Amplifyはs3バケットのプロビジョニングを通じて抽象化を支援しますが、お客様の適切なレベルの制御を理解することが重要です。

`amplify add storage`を実行すると、CLIはCognito Identity Pool Roleを使用してバケットに適切なIAMポリシーを設定します。CRUD(作成、更新、読み取り、削除)ベースのアクセス許可を追加するオプションも用意されているため、認証済みユーザーとゲストユーザーはこれらのレベル内で制限されたアクセス許可が付与されます。
