<InlineFilter filters={['javascript', 'react-native', 'angular', 'nextjs', 'react', 'vue']}>

ストレージバケットから保存されたデータを削除します。ファイルを削除するには、完全に指定された`path`を提供する必要があります。

ファイルは現在のユーザーのみ削除できます。削除機能は他のユーザーに関連付けられたファイルには適用されません。

<BlockSwitcher>
<Block name="With Path (Above v6.2.0)">
```javascript
import { remove } from 'aws-amplify/storage';

try {
  await remove({ 
    path: 'public/album/2024/1.jpg',
    // Alternatively, path: ({identityId}) => `protected/${identityId}/album/2024/1.jpg`
  });
} catch (error) {
  console.log('Error ', error);
}
```
</Block>
<Block name="With Key (Deprecated)">
```javascript
import { remove } from 'aws-amplify/storage';

try {
  await remove({ 
    key: 'album/2024/1.jpg', 
    options: { 
      accessLevel: 'guest' // defaults to `guest` but can be 'private' | 'protected' | 'guest'
    } 
  });
} catch (error) {
  console.log('Error ', error);
}
```
</Block>
</BlockSwitcher>
