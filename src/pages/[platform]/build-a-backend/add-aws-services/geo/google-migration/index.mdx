Google Mapsまたは他の類似のマッププロバイダーを使用していて、Amplify Geoまたはアマゾン ロケーション サービスに切り替えたいですか？このチュートリアルでは、既存のGoogle Maps APIを取得し、Amplify Geoの使用に切り替える方法を説明します。

## はじめに

Amplify Geoは、位置情報ベースの機能を使用するためのAPIを提供します。内部的にAmplifyは[アマゾン ロケーション サービス](https://aws.amazon.com/location/)を使用し、オープンソースマッピングライブラリ[MapLibre](https://maplibre.org/)と連携するように設計されています。

このガイドでは、Google Maps JavaScript APIとHTML、CSS、JavaScriptを含むフロントエンドウェブ開発の概念に既に精通していることを想定しています。

このチュートリアルを完了するには、以下が必要です：

- **Amplify Geo**
- **テキストエディタ**

## Amplify GeoとGoogle Mapsの主な違い

### 座標の規約

Amplify Geoを使用する場合とGoogle Mapsを使用する場合の主な違いは、Google Maps Platformでは座標を指定する規約が`[lat, lng]`であることです。Amplify Geoに移行する場合、順序は`[lng, lat]`にスワップされます。これは[geojson仕様](https://geojson.org/)に合わせるために行われました。この仕様はMapLibreでも使用されています。

### 認可

Google Maps PlatformやMapboxなどの他の同様のサービスを使用する場合、まずGoogle Cloud Consoleに移動してAPIを設定し、APIキーを作成してから、Google Maps JS APIをリクエストする際にAPIキーを使用します。Amplify Geoの場合、代わりにAmplify Authをセットアップし、`MapView`コンポーネントが`amplify_outputs.json`ファイルから認証構成を読み込みます。バックグラウンドでAmplify AuthはAmazon Cognitoを使用してロケーション サービスへのアクセスを備えたクライアント認証情報をセットアップし、Geoは位置情報関連のAPI呼び出しを行う際にこれらの認証情報を使用します。Amplify AuthとGeoの設定に関する詳細情報は、以下の`Amplifyのセットアップ`セクションにあります。

### Amplifyのセットアップ

1. [Geo Mapリソース](/[platform]/build-a-backend/add-aws-services/geo/set-up-geo/)をセットアップする必要があります。マップを作成するための指示に従ってください。
2. ワークフローが完了したら、`index.html`ファイルと同じディレクトリに`amplify_outputs.json`ファイルが必要です。
3. `index.html`ファイルを保存します。
