## マップにロケーション検索機能を追加

まず、[ロケーション検索を構成](/[platform]/build-a-backend/add-aws-services/geo/configure-location-search/)または[既存の Amazon Location Service リソースを使用](/[platform]/build-a-backend/add-aws-services/geo/existing-resources/)のいずれかの指示を使用して検索インデックスリソースをプロビジョニングし、アプリを構成しており、アプリケーションで既に[マップの表示](/[platform]/frontend/geo/maps)を設定していることを確認してください。

<Callout>

**注:** React の場合、[Amplify UI Location Search コンポーネント](https://ui.docs.amplify.aws/react/connected-components/geo#location-search)を使用して検索結果を生成して表示できます。

</Callout>

マップにロケーション検索 UI コンポーネントを追加するには、[maplibre-gl-geocoder](https://github.com/maplibre/maplibre-gl-geocoder) ライブラリを使用できます。`maplibre-gl-js-amplify` パッケージは、ユーティリティ関数 `createAmplifyGeocoder()` をエクスポートすることで、`maplibre-gl-geocoder` を Amplify Geo と統合するのを簡単にします。これにより `maplibre-gl-geocoder` のインスタンスが返されます。いくつかの事前定義設定が含まれており、UI コンポーネントをカスタマイズするための[すべてのオプション](https://maplibre.org/maplibre-gl-geocoder/types/MaplibreGeocoderOptions.html)に対応しています。

次のコマンドで必要な依存関係をインストールします。

```bash title="Terminal" showLineNumbers={false} 
npm add @maplibre/maplibre-gl-geocoder maplibre-gl@1 maplibre-gl-js-amplify
```

> **注:** `maplibre-gl-js-amplify` バージョン `4.0.0` 以上がインストールされていることを確認してください。

まず、ロケーション検索 UI コンポーネントを追加するマップを作成します。[マップの作成と表示](/[platform]/frontend/geo/maps)のガイドを参照してください。

次に、`createAmplifyGeocoder()` を使用して `MaplibreGeocoder` の新しいインスタンスを取得し、ロケーション検索 UI コンポーネントをマップに追加します。

> **注:** パッケージバンドラー (webpack、rollup など) が CSS ファイルを処理するように構成されていることを確認してください。webpack ドキュメント[ここ](https://webpack.js.org/loaders/css-loader/)を確認してください。

```javascript
import { createMap, createAmplifyGeocoder } from "maplibre-gl-js-amplify";
import maplibregl from "maplibre-gl";
import "maplibre-gl/dist/maplibre-gl.css";
import "@maplibre/maplibre-gl-geocoder/dist/maplibre-gl-geocoder.css";
import "maplibre-gl-js-amplify/dist/public/amplify-geocoder.css"; // Optional CSS for Amplify recommended styling

async function initializeMap() {
    const el = document.createElement("div");
    el.setAttribute("id", "map");
    document.body.appendChild(el);

    const map = await createMap({
        container: "map",
        center: [-123.1187, 49.2819], // [Longitude, Latitude]
        zoom: 11,
    })

    map.addControl(createAmplifyGeocoder());
}

initializeMap();
```

### 検索アイコンをカスタマイズ

[maplibre-gl-geocoder](https://github.com/maplibre/maplibre-gl-geocoder) で使用される検索アイコンをカスタマイズして、選択したイメージを使用できます。[MapLibre マーカー](https://maplibre.org/maplibre-gl-js/docs/API/#markers-and-controls)は、カスタム画像を渡すときに [HTMLElement](https://developer.mozilla.org/en-US/docs/Web/HTML/Element) が必要です。

```javascript

const geocoder = createAmplifyGeocoder({ showResultMarkers: { element: icon } });

```

## ロケーションベースの検索機能

Amplify Geo では、テキスト、住所、または地理座標でロケーションを検索できます。

### テキスト、住所、ビジネス名、都市などで検索

`Geo.searchByText()` API を使用すると、住所、名前、都市、地域などの自由形式テキストで場所や関心のあるポイントを検索できます。

```javascript
import { Geo } from "@aws-amplify/geo"

Geo.searchByText("Amazon Go Store")
```

次を提供することで、検索結果をさらにカスタマイズできます:
- `countries` - 検索結果を特定の国に限定します ([ISO Alpha-3 国コード](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-3)で指定)
- `maxResults` - 最大結果セットを制限します
- `biasPosition` - 検索の発信元ロケーションとして機能します
- `searchAreaConstraints` - 検索対象の領域を制限します
- `searchIndexName` - デフォルト以外の Location Service 検索インデックスリソースを使用します

 **注:** `biasPosition` と `searchAreaConstraints` パラメータの両方を同時に指定するとエラーが返されます。

```javascript
const searchOptionsWithBiasPosition = {
  countries: string[], // Alpha-3 country codes
  maxResults: number, // 50 is the max and the default
  biasPosition: [
    longitude // number
    latitude // number,
  ], // Coordinates point to act as the center of the search
  searchIndexName: string, // the string name of the search index
}

const searchOptionsWithSearchAreaConstraints = {
  countries: ["USA"], // Alpha-3 country codes
  maxResults: 25, // 50 is the max and the default
  searchAreaConstraints: [SWLongitude, SWLatitude, NELongitude, NELatitude], // Bounding box to search inside of
  searchIndexName: string, // the string name of the search index
}

Geo.searchByText('Amazon Go Stores', searchOptionsWithBiasPosition)
```

これにより、検索制約に一致する場所とその座標が返されます。場所には、以下の例に示すように追加のメタデータが含まれることもあります。

```javascript
// returns
[
  {
    geometry: {
      point:
        [
          -122.34014899999994, // Longitude point
          47.61609000000004 // Latitude point
        ],
    },
    addressNumber: "2131" // optional string for the address number alone
    country: "USA" // optional Alpha-3 country code
    label: "Amazon Go, 2131 7th Ave, Seattle, WA, 98121, USA" // Optional string
    municipality: "Seattle" // Optional string
    neighborhood: undefined // Optional string
    postalCode: "98121" // Optional string
    region: "Washington" // Optional string
    street: "7th Ave" // Optional string
    subRegion: "King County" // Optional string
  }
]
```

### 座標で検索

`Geo.searchByCoordinates()` API は、座標ポイントを取得し、そのポイントでマップ上で見つかったものに関する情報を返す逆ジオコーダーです。返されたオブジェクトは、上記の `searchByText()` API と同じ形状です。

```javascript
import { Geo } from "@aws-amplify/geo";

Geo.searchByCoordinates([longitudePoint, latitudePoint])
```

オプションで、`maxResults` パラメータで結果セットを制限するか、`searchIndexName` パラメータでデフォルト検索インデックスをオーバーライドできます。

```javascript
const searchOptionsWithBiasPosition = {
  maxResults: number, // 50 is the max and the default
  searchIndexName: string, // the string name of the search index
}

Geo.searchByCoordinates([-122.3399573, 47.616179], searchOptionsWithBiasPosition)
```

### 提案を検索

`Geo.searchForSuggestions()` API を使用すると、場所、住所、都市、地域などの自由形式テキストで提案を検索できます。

```javascript
import { Geo } from "@aws-amplify/geo";

Geo.searchForSuggestions("Amazon Go Store")
```

`Geo.searchByText()` API と同様に、以下を提供することで検索結果をさらにカスタマイズできます:
- `countries` - 検索結果を特定の国に限定します ([ISO Alpha-3 国コード](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-3)で指定)
- `maxResults` - 最大結果セットを制限します
- `biasPosition` - 検索の発信元ロケーションとして機能します
- `searchAreaConstraints` - 検索対象の領域を制限します
- `searchIndexName` - デフォルト以外の Location Service 検索インデックスリソースを使用します

 **注:** `biasPosition` と `searchAreaConstraints` パラメータの両方を同時に指定するとエラーが返されます。

```javascript
const searchOptionsWithBiasPosition = {
  countries: string[], // Alpha-3 country codes
  maxResults: number, // 50 is the max and the default
  biasPosition: [
    longitude // number
    latitude // number,
  ], // Coordinates point to act as the center of the search
  searchIndexName: string, // the string name of the search index
}

const searchOptionsWithSearchAreaConstraints = {
  countries: ["USA"], // Alpha-3 country codes
  maxResults: 25, // 50 is the max and the default
  searchAreaConstraints: [SWLongitude, SWLatitude, NELongitude, NELatitude], // Bounding box to search inside of
  searchIndexName: string, // the string name of the search index

```
これにより、検索制約に一致する提案 (場所とそれぞれの `placeId` (利用可能な場合)) のリストが返されます。

```javascript
// returns
[
  {
    text: "Amazon Go, 2131 7th Ave, Seattle, WA, 98121, USA",
    placeId: "8fd9d4c6-2527-4190-a7df-0dae352c9dc6"
  },
  {
    text: "Amazon Go, 1906 Terry Ave, Seattle, WA, 98101, USA",
    placeId: "5d04d071-dea2-4d86-bfce-86bd6a8f4787"
  }
]
```

以下のように提案のリストで `placeId` が利用できない場合は、``searchByText`` を使用してテキストで選択した場所を検索します。

```javascript

// returns
[
  {
    text: "Amazon Go",
  },
  {
    text: "Amazon 4-star",
  }
]
```

これにより、検索テキストに一致する場所とその座標が返されます。

<InlineFilter filters={['android']}>
`AmplifyMapView` は、組み込みのロケーション検索、検索フィールド、および場所マーカーを提供します。Maps ページの [AmplifyMapView セクション](/[platform]/frontend/geo/maps/#amplifymapview)に従って、`AmplifyMapView` をセットアップしてください。

<InlineFilter filters={['swift']}>
ロケーション検索 UI コンポーネントを `AMLMapView` に追加するには、目的のレイアウトでビューに `AMLSearchBar` を追加します。検索時に、`Geo.Place` は `AmplifyMapLibre.createFeatures(places)` を使用して `MGLPointFeature` に変換されます。最後に、それらの変換された `MGLPointFeature` を `mapState.features` に割り当てます。または、`AMLSearchBar` など複数の事前構成された UI コンポーネントを含む `AMLMapCompositeView` を直接利用できます。

```swift
import SwiftUI
import AmplifyMapLibreUI
import AmplifyMapLibreAdapter
import Amplify

struct MyMapView: View {

    @StateObject private var mapState = AMLMapViewState()
    @State private var searchText = ""
    @State private var displayState: AMLSearchBar.DisplayState = .map

    var body: some View {
        ZStack(alignment: .top) {
            AMLMapView(mapState: mapState)
                .edgesIgnoringSafeArea(.all)

            AMLSearchBar(
                text: $searchText,
                displayState: $displayState,
                onEditing: { },
                onCommit: search,
                onCancel: { mapState.features = [] }
            )
            .padding()
        }
    }

    private func search() {
        let searchArea = Geo.SearchArea.near(mapState.center)
        let searchOptions = Geo.SearchForTextOptions(area: searchArea)
        Task {
            do {
                let places = try await Amplify.Geo.search(for: searchText, options: searchOptions)
                await MainActor.run {
                    self.mapState.features = AmplifyMapLibre.createFeatures(places)
                }
            } catch let error as Geo.Error {
                print("Failed to search: \(error)")
            } catch {
                print("Unexpected error: \(error)")
            }
        }
    }
}
```

### 座標を検索

`Amplify.Geo.search(for coordinates:)` API は、座標ポイントを取得し、そのポイントでマップ上で見つかったものに関する情報を返す逆ジオコーダーです。

```swift
do {
    let places = try await Amplify.Geo.search(for: coordinates)
    dump(places)
} catch let error as Geo.Error {
    print("Failed to search: \(error)")
} catch {
    print("Unexpected error: \(error)")
}
```

`Geo.SearchForCoordinatesOptions` 内で以下のパラメータを指定することで、検索結果を改善できます
- `maxResults` - 最大結果セットを制限します (デフォルトは 50)

```swift
let options = Geo.SearchForCoordinatesOptions(maxResults: 25)
```
