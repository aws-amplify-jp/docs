Apple は、アプリを App Store に提出する際に、アプリのデータ使用ポリシーを提供することを要求しています。詳細については、Apple の [ユーザープライバシーとデータ使用](https://developer.apple.com/app-store/user-privacy-and-data-use/)を参照してください。Amplify ライブラリは、開発者が所有および管理する AWS リソースと相互作用するために使用されます。ライブラリはその API の使用方法を予測できないため、アプリで収集されたデータを正確に反映するプライバシーマニフェストを提供するのは開発者の責任です。以下は、Apple によって特定されたさまざまなカテゴリと、Amplify ライブラリで使用される対応するデータタイプです。

ライブラリを利用することで、Amplify はアクセスされた AWS サービスから API 使用メトリクスを収集します。このプロセスには、AWS サービスに対する要求にユーザーエージェントを追加することが含まれます。ユーザーエージェントヘッダーには、Amplify ライブラリバージョン、オペレーティングシステム名、およびバージョンに関する情報が含まれます。AWS はこのデータを収集して、ライブラリの使用に関連するメトリクスを生成します。この情報はユーザーの ID にリンクされておらず、Apple のプライバシーとデータ使用ガイドラインで説明されているように追跡目的には使用されません。

Analytics や Auth などの Amplify カテゴリの中には、データをローカルデバイスに保持するものがあります。そのようなデータの一部は、ユーザーがデバイスからアプリをアンインストールするときに自動的に削除されます。

Amplify は Auth 情報をローカル[システムキーチェーン](https://developer.apple.com/documentation/security/keychain_services)に保存します。これは、アプリがアンインストールされるときにデータが削除されるかどうかについて、特定の動作を保証しません。

この Auth 情報をいつクリアするかを決定することは SDK が汎用的な方法で行うことはできないため、アプリ開発者はサインアウトによってデータをクリアするタイミングを決定する必要があります。これを実現するための 1 つの戦略は、[UserDefaults](https://developer.apple.com/documentation/foundation/userdefaults)を使用してアプリが初めて起動されているかどうかを検出し、アプリが以前に起動されていない場合は[`Auth.signOut()`](/[platform]/frontend/auth/sign-out/)を呼び出すことです。
