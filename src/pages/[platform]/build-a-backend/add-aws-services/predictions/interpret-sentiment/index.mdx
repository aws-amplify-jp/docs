## APIの使用

テキストを分析して、主要フレーズ、センチメント（肯定的、否定的、中立的）、または構文（代名詞、動詞など）を検出できます。また、テキスト内の名前や場所などのエンティティを検出したり、言語検出を実行したりすることもできます。

```ts
import { Predictions } from '@aws-amplify/predictions';

const result = await Predictions.interpret({
  text: {
    source: {
      text: textToInterpret,
    },
    type: 'ALL'
  }
})
```
