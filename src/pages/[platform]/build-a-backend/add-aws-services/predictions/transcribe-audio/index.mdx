## APIの使用

PCMオーディオバイトバッファをテキストに変換できます。マイクからの録音など。

```ts
import { Predictions } from '@aws-amplify/predictions';

const { transcription } = await Predictions.convert({
  transcription: {
    source: {
      bytes
    }
  }
})
```

サポートされているすべての言語と言語固有の機能の完全なリストを確認するには、[サポートされている言語リスト](https://docs.aws.amazon.com/transcribe/latest/dg/supported-languages.html)を参照してください。言語データ入力タイプがストリーミングをサポートする必要があります。Amplify Predictionsで機能するようにするためです。
