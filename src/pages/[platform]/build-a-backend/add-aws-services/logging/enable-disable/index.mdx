  description: 'ロギングを有効または無効にする方法について詳しく説明します',
  platforms: [
    'swift',
    'android'
  ]
};

    }
  };

このセクションでは、Amplify Logger を使用するときにロギングを有効または無効にする方法について説明します。デフォルトで有効になっていますが、`amplifyconfiguration_logging` ファイルで無効にすることもできます。



<InlineFilter filters={['android']}>

<BlockSwitcher>
<Block name="Java">

Amplify Logger を有効にします。

```java
Amplify.Logging.enable();
```

Amplify Logger を無効にします。

```java
Amplify.Logging.disable();
```

</Block>
<Block name="Kotlin">

Amplify Logger を有効にします。

```kotlin
Amplify.Logging.enable()
```

Amplify Logger を無効にします。

```kotlin
Amplify.Logging.disable()
```

</Block>
<Block name="RxJava">

Amplify Logger を有効にします。

```java

```

Amplify Logger を無効にします。

```java
Amplify.Logging.disable();
```

</Block>
</BlockSwitcher>
