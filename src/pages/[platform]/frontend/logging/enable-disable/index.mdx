このセクションでは、Amplify Loggerを使用する際にロギングを有効または無効にする方法を学習します。デフォルトでは有効になっていますが、`amplifyconfiguration_logging`ファイルで無効にすることができます。



<InlineFilter filters={['android']}>

<BlockSwitcher>
<Block name="Java">

Amplify Loggerを有効にします。

```java
Amplify.Logging.enable();
```

Amplify Loggerを無効にします。

```java
Amplify.Logging.disable();
```

</Block>
<Block name="Kotlin">

Amplify Loggerを有効にします。

```kotlin
Amplify.Logging.enable()
```

Amplify Loggerを無効にします。

```kotlin
Amplify.Logging.disable()
```

</Block>
<Block name="RxJava">

Amplify Loggerを有効にします。

```java
Amplify.Logging.enable();
```

Amplify Loggerを無効にします。

```java
Amplify.Logging.disable();
```

</Block>
</BlockSwitcher>



</InlineFilter>
