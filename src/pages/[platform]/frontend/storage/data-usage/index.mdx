Appleでは、アプリをApp Storeに提出する際に、アプリのデータ使用ポリシーを提供することが必須です。詳細は、Appleの[ユーザープライバシーとデータ使用](https://developer.apple.com/app-store/user-privacy-and-data-use/)を参照してください。Amplifyライブラリは、開発者が所有・管理するAWSリソースと連携するために使用されます。ライブラリはそのAPIの使用方法を予測することができないため、アプリが収集したデータを正確に反映するプライバシーマニフェストを提供するのは開発者の責任です。以下は、Appleが特定した異なるカテゴリーと、Amplifyライブラリが使用する対応するデータタイプです。

ライブラリを利用することで、Amplifyはアクセスされることになるまるで利用するAWSサービスからのAPI使用メトリクスを収集します。このプロセスには、AWSサービスへのリクエストにユーザーエージェントを追加することが含まれます。ユーザーエージェントヘッダーには、Amplifyライブラリのバージョン、オペレーティングシステム名、およびバージョンに関する情報が含まれます。AWSはこのデータを収集して、ライブラリ使用に関連するメトリクスを生成します。この情報はユーザーのIDに紐付けられておらず、Appleのプライバシーおよびデータ使用ガイドラインで説明されているように、追跡目的で使用されていません。

プライバシーマニフェストの強化について特定の懸念事項や追加情報が必要な場合は、遠慮なくお問い合わせください。

## データの削除

Analytics、Auth、DataStoreなどのAmplifyカテゴリの一部は、ローカルデバイスにデータを保持します。そのデータの一部は、ユーザーがデバイスからアプリをアンインストールするときに自動的に削除されます。

Amplifyはauth情報をローカル[システムキーチェーン](https://developer.apple.com/documentation/security/keychain_services)に保存しますが、アプリのアンインストール時にデータが削除されるかどうかについては、特定の動作を保証しません。

このauth情報をいつクリアするかを決定することはSDKが一般的な方法で行うことができないため、アプリ開発者はサインアウトしてデータをクリアするタイミングを決定する必要があります。これを達成するための1つの戦略は、[UserDefaults](https://developer.apple.com/documentation/foundation/userdefaults)を使用してアプリが初めて起動するかどうかを検出し、アプリが以前に起動されていない場合は[`Auth.signOut()`](/[platform]/frontend/auth/sign-out/)を呼び出すことです。
