AWS Amplify Hostingは、高速で安全、かつ信頼性の高い静的およびサーバーサイドレンダリングアプリをスケーリングして実行するための完全マネージド型のCI/CDおよびホスティングサービスです。このサービスは、React、Angular、Vue、Next.js、Nuxt.js、Gatsbyなどの最新Webフレームワークをサポートしています。

AWS Amplify Hostingは完全マネージド型のサービスであるため、その documentation は AWS Documentation サイトにあります。カスタムドメイン、リダイレクト、その他の機能などのホスティング機能について詳しくは、Hosting documentation をご覧ください。
